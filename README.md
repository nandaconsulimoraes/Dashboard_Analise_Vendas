# 🍫 Análise de Vendas de Chocolates

Projeto de **Análise Exploratória de Dados (EDA)** desenvolvido em Python com o objetivo de analisar dados de vendas de chocolates, identificando padrões relacionados a produtos, países, faturamento e quantidade de caixas vendidas.

O projeto foi desenvolvido como parte dos meus estudos em **Análise de Dados**, aplicando conceitos de tratamento, manipulação, análise e visualização de dados com Python.

---

## 🎯 Objetivos

- Realizar a limpeza e preparação dos dados;
- Explorar as informações disponíveis no dataset;
- Analisar o desempenho dos produtos;
- Identificar os países com maior faturamento;
- Comparar quantidade de caixas vendidas e faturamento;
- Criar visualizações para facilitar a interpretação dos dados;
- Extrair insights a partir das análises realizadas.

---
## 💡 Principais Insights

A análise permitiu identificar alguns pontos relevantes:

- O produto com maior volume de caixas vendidas não foi o mesmo produto com maior faturamento;
- O faturamento varia entre os diferentes produtos mesmo quando a quantidade de caixas vendidas é semelhante;
- Os países apresentam diferentes níveis de participação no faturamento total;
- A quantidade de caixas enviadas, analisada isoladamente, não apresenta uma relação linear forte com o valor das vendas;
- A análise por produto permite observar diferenças que ficam menos evidentes quando todos os produtos são analisados em conjunto.
